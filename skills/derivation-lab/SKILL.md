# 专业推导（Derivation Lab）

原则：**推导是代码，不是散文。** 每个结论至少两条独立路径验证；不成立的近似如实标注。

## 目录约定

```
experiments/derivations/<id>/
  derive.py       符号推导脚本（假设、符号约定、近似条件写在文件头）
  validate.py     交叉验证脚本（数值/量纲/极限/展开/文献对照）
  validation.md   验证记录：每条结论 → 用了哪几类验证 → 结果
  result.tex      LaTeX 片段（公式编号与代码变量一一对应）
  notes.md        推导思路、卡住的点、被否掉的分支（很重要，别删）
```

## 工作流

### 1. 先把问题形式化
写清五件事，缺一项就不要开始推导：
- 目标量是什么（表达式 / 不等式 / 极限 / 存在性）
- 符号与单位约定（SI / 自然单位；哪些是无量纲比）
- 已知关系与边界条件
- 允许的近似及其**成立区间**
- 判据：什么结果算"推出来了"（例如与文献某式一致、或数值残差 < 1e-10）

### 2. 符号推导（sympy）
```python
# derive.py —— 头部必须写清假设
import sympy as sp
x, t, k = sp.symbols('x t k', real=True)
m, w = sp.symbols('m omega', positive=True)   # 用 positive/real 减少无谓分支

# 假设与近似（写明成立区间，如：k*x << 1）
# 推导：先化简再求解，保留中间步骤便于核对
expr = sp.expand(sp.simplify((x + 1)**2 - (x - 1)**2))
sol = sp.solve(sp.Eq(sp.diff(expr, x), 0), x)

# 输出可复制的 LaTeX（编号与 notes.md 对应）
print(sp.latex(expr))
```
要点：
- 符号带 `positive=True` / `real=True` 假设，否则化简会给出分段结果。
- 近似用 `sp.series(...).removeO()` 或显式代入小参数，**并记录丢弃项的量级**。
- 复杂积分/求和先试 `simplify` → `trigsimp` / `expand_func` → 数值兜底，别死磕符号解。
- 解不唯一时列出全部分支，并说明物理/数学上如何取舍。

### 3. 量纲与不确定度（pint / uncertainties）

符号推导对，量纲错、误差传错，结论照样不能用。**本机已装 `pint` 与 `uncertainties`**：

```python
import pint
u = pint.UnitRegistry()
g, L = 9.81 * u.m / u.s**2, 2.0 * u.m
T = 2 * 3.141592653589793 * (L / g) ** 0.5
print(T.to(u.s))            # 量纲自动传播；单位不一致直接抛 DimensionalityError
```

```python
from uncertainties import ufloat
m, v = ufloat(2.0, 0.05), ufloat(3.0, 0.1)   # 值 ± 1σ
E = 0.5 * m * v**2                            # 误差按一阶传播
print(E)                                      # 9.0+/-0.6
```

规则：
- 每条带物理量的结论，用 pint 跑一遍单位传播；量纲不齐就是推导有错。
- 输入有测量误差时，用 uncertainties 给出结果的不确定度，并写清是 1σ 还是 95% CI。
- 非线性强或误差大（相对误差 >10%）时，一阶传播不可靠 → 改用蒙特卡洛（`numpy` 采样 10⁵ 次）交叉核对。
- 无量纲化：先判断哪些组合是无量纲数（如 Reynolds、Mach），能减少一个自由度。
- 纯数学结论（无物理量）跳过 pint，但仍要做第 4 节的极限/展开验证。

### 4. 交叉验证（至少两类，写进 validation.md）
1. **数值代入**：随机取 3–5 组参数（含边界值）比较符号结果与数值积分/数值解，报告最大相对误差。
2. **量纲/单位**：用 pint 跑单位传播（见第 3 节）；无量纲量的组合必须是无量纲的。
2b. **不确定度**：输入误差如何传到最后（解析传播 vs 蒙特卡洛），给出 1σ 区间。
3. **极限与边界**：`x→0`、`x→∞`、参数取 0/1 等特例，结果应退化为已知形式。
4. **小参数展开**：与解析展开的前若干阶系数比对。
5. **文献对照**：与已发表结果在同一约定下比较（注意符号约定、单位制、坐标系差异）。
6. **数值反例搜索**：在参数空间扫一遍找反例；找到就说明结论有适用边界。

```python
# validate.py 骨架
import numpy as np
from scipy.integrate import quad
# 符号解 vs 数值解
for p in [(0.5, 1.0), (2.0, 3.0), (1e-3, 1.0)]:
    num, _ = quad(lambda s: np.exp(-p[0]*s), 0, np.inf)
    assert abs(num - 1/p[0]) / abs(1/p[0]) < 1e-8
```

### 5. 成文（LaTeX）
- `result.tex` 只放公式与一步一句的推导链，编号与 `derive.py` 变量注释对应。
- 每个近似标注成立条件（例如 `$kx \ll 1$`），并给出失效时的行为。
- 本机有 `pdflatex`：可直接编译成 PDF 作为报告附件（无 pandoc/xelatex，用 `article` 类 + 标准宏包）。
- 图表用 matplotlib 出 PDF/SVG，随工件归档。

### 6. 归档
`record_save` 归档整个 `experiments/derivations/<id>/`（脚本 + validation.md + tex + 图），
`notes` 写明：符号约定、近似区间、验证结论（通过/在哪个区间失效）、与文献的一致性。
引用结论时写工件名与版本。

## 常见坑

- **分支切割**：开方/对数/反三角的多值性被忽略，导致符号解只在部分区域成立。
- **奇点与发散**：先找极点，再谈化简；数值验证要避开奇点附近。
- **近似越界**：把 `x≪1` 的展开用到 `x~1`，结果"看起来对"但系数全错。
- **约定不一致**：傅里叶变换的 2π 位置、度规符号、单位制（SI vs 自然单位）没对齐。
- **符号假设缺失**：sympy 给出分段表达式，被误读成单一结论。
- **只做一类验证**：数值对上了但量纲错（或反之），必须交叉。

## 输出要求

- 结论一句话 + 适用条件；不成立的近似写明失效区间。
- 每条结论附「验证方式 + 结果」（例：数值残差 1e-12；量纲一致；x→0 退化为 1）。
- 与文献不一致时，先排查约定差异，再判断谁错；不要默认文献正确或自己正确。
